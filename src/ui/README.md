# ui

React components that implement the `ui-contracts/` contracts, and the kit that renders the Presenter's pages on the server (props checked with Hashbrown's schemas, so the library never reaches the phone). Their visible text is in Spanish (the audience's language).

- May import: `ui-contracts/`, `domain/`, React and `@hashbrownai/core`.
- May not import: `application/` or `infrastructure/`.
